# AEye

基于类 YOLO 的屏幕目标检测 + Esp32开发板进行机外信号处理 + 自动化触发


## 硬件说明

为保证程序在各类平台上的通用性，鼠标移动由外部 ESP32 开发板 + Arduino 固件 输出模拟信号控制（通过串口/Wi-Fi 与 PC 通信），而不是直接由程序鼠标 API 驱动。


## Quick Start
```bash
git clone https://github.com/your-username/AEye.git
cd AEye
python main.py
# 接下来根据提示选择监控窗口即可，默认选择0号窗口监视全屏
```
默认点击 ` 键开关功能
功能开启后默认点击鼠标中键触发动作

## 注意

* 请先确保 ESP32 已烧录 Arduino 固件并与电脑通信正常。
* 仓库中不包含任何商业封闭模型权重，使用开源Yolo架构，可根据需要对权重进行替换。
